# Project Summary
Atoms Cloud Marketplace is a Persian RTL beauty marketplace where buyers browse storefronts, add items to cart, and complete checkout with authentication, quiz, and booking. Payments are processed via Zarinpal (sandbox supported) with callback-driven verification and cart cleanup only after confirmed success; the UI then shows checkout result/confirmation.

# Project Module Description
## Frontend (React / UI + Pages)
- Site-wide layout:
  - Adds a global, RTL-friendly multi-column Footer rendered across the app shell.
  - Adds a ScrollToTop helper to reset scroll on route changes (and to smoothly scroll when a hash is present).
- Information pages:
  - Implements dedicated customer-facing pages for About Us, Contact Us, Terms & Conditions, and Refund Policy using a shared InfoPageLayout.
  - Footer links use React Router navigation (no full page reloads).

## Backend (Checkout + Payment)
- Zarinpal payment flow:
  - Creates pending payment orders, verifies gateway callbacks idempotently, and clears cart only after confirmed successful payment.
  - Supports sandbox mode and validates callback origin composition before verification.

# Usage
## Frontend
- In `app/frontend`:
  - `pnpm install`
  - `pnpm run build`
  - Start via `./start_app_v2.sh`

## Backend
- Set `ZARINPAL_USE_SANDBOX` to enable sandbox mode.
- Run DB migrations to create payment order tables/fields before using checkout.
- Set `PUBLIC_SITE_URL` (or `ZARINPAL_CALLBACK_BASE_URL`) so the callback uses `<origin>/payment/callback`.
